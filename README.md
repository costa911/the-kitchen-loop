# The Kitchen Loop

A personal recipe management and meal planning app built with vanilla HTML, CSS and JavaScript. No frameworks, no dependencies, no backend — just a single file that runs in any browser.

---

## What it does

- **Recipe library** — store all your recipes with ingredients, categories, notes and links
- **Cook logging** — log every time you cook a recipe and track how many times you've made it
- **Fortnightly meal planner** — auto-generate a 2-week dinner plan with a lunch rotation and weekly dessert
- **Smart shopping list** — automatically generated from your plan, split into big shop, fresh top-ups and staples to check
- **Fully editable** — edit any recipe directly, update categories, ingredients, links and notes on the fly

## Categories

Recipes can belong to one or more of: **Dinner**, **Pasta**, **Dessert**, **Lunch**, **Breakfast**

## Tech

- Vanilla HTML, CSS, JavaScript — zero dependencies
- `localStorage` for persistent data storage
- Single file — `index.html` is the entire app

## How to run

**Locally:**
Just open `index.html` in any browser. That's it.

**Via GitHub Pages:**
1. Fork or clone this repo
2. Go to Settings → Pages
3. Set source to `main` branch, root folder
4. Your app will be live at `https://yourusername.github.io/the-kitchen-loop`

## Data & privacy

All data is stored locally in your browser's `localStorage`. Nothing is sent to any server. Clearing your browser data will reset the app.
